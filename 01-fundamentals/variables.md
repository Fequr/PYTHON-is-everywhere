# Variables in Python

What Are Variables?

Variables are names that refer to objects in memory. They allow us to store and reuse data.

# Creating Variables

name = "Alex" 
age = 18
height = 1.85
is_student = True

Python automatically determines the type of an object.

Multiple Assignment

x, y = 10, 20
a = b = 0

# Naming Rules

* Names can contain letters, numbers, and underscores.
* Names cannot start with a number.
* Names are case-sensitive.
* Use snake_case for variable names.
* Avoid Python keywords such as class, if, and for.

# Constants

Python does not have strict constants. By convention, uppercase names represent values that should not change.

MAX_RETRIES = 3
PI = 3.14159

# Important

* = assigns a value.
* == compares two values.
* Variables can be reassigned.

score = 10
score = 20
